= amigo

A small typed wrapper around Go's `http.ServeMux`.

[source,go]
----
type GetUserInput struct {
    ID            uuid.UUID `path:"id"`
    Authorization string `header:"Authorization"`
    Session       string `cookie:"session"`
}

type GetUserOutput struct {
    ID uuid.UUID `json:"id"`
}

func GetUser(
    ctx context.Context,
    input GetUserInput,
) (GetUserOutput, error) {
    return GetUserOutput{ID: input.ID}, nil
}

func main() {
    app := amigo.New()
    app.GET("/users/{id}", GetUser)

    log.Fatal(app.Run(":8080"))
}
----

The framework binds path, query, header, and cookie parameters. A field named
`Body` is decoded as strict JSON. Supported parameter types include strings,
booleans, numbers, slices, pointers, `time.Time`, and types implementing
`encoding.TextUnmarshaler`, such as Go 1.27's `uuid.UUID`. `GET`, `POST`, `PUT`,
`PATCH`, and `DELETE` are available.

Routes can be grouped in nested routers:

[source,go]
----
api := amigo.NewRouter(
    amigo.Prefix("/api"),
    amigo.Tags("api"),
)
users := amigo.NewRouter(
    amigo.Prefix("/users"),
    amigo.Tags("users"),
)
users.GET("/{id}", GetUser, amigo.Tags("read"))

api.Include(users)

app := amigo.New()
app.Include(api)
----

Router options are optional, so `amigo.NewRouter()` is valid. Route options are
optional too. On the first request, the API recursively builds complete
`Operation` values and registers them in its `http.ServeMux`. Prefixes, tags,
and middleware are inherited from parent routers. The final tags above are
`["api", "users", "read"]`.

`Run` builds the router tree once and starts `http.ListenAndServe`. `Handler`
can be used when another server or tool needs the built `http.Handler`, while
`Operations` exposes a snapshot of the final route metadata. Routers must be
configured from one goroutine before building. Building freezes the
configuration, after which the API can serve requests concurrently. `API` also
implements `http.Handler` for direct compatibility with `net/http`.
