= amigo

A small typed wrapper around Go's `http.ServeMux`.

[source,go]
----
type GetUserInput struct {
    ID            uuid.UUID `path:"id"`
    Authorization string `header:"Authorization"`
    Session       string `cookie:"session"`
}

type GetUserOutput struct {
    ID uuid.UUID `json:"id"`
}

func GetUser(
    ctx context.Context,
    input GetUserInput,
) (GetUserOutput, error) {
    return GetUserOutput{ID: input.ID}, nil
}

func main() {
    app := amigo.New()
    app.GET("/users/{id}", GetUser)

    log.Fatal(app.Run(":8080"))
}
----

The framework currently binds required path parameters, headers, and cookies.
Supported field types are strings, booleans, signed and unsigned integers,
floating-point numbers, and Go 1.27's `uuid.UUID`. `GET`, `POST`, `PUT`,
`PATCH`, and `DELETE` are available. Query parameters, request bodies, defaults,
and OpenAPI generation are intentionally not implemented yet.

Routes can be grouped in nested routers:

[source,go]
----
api := amigo.NewRouter(
    amigo.Prefix("/api"),
    amigo.Tags("api"),
)
users := amigo.NewRouter(
    amigo.Prefix("/users"),
    amigo.Tags("users"),
)
users.GET("/{id}", GetUser, amigo.Tags("read"))

api.Include(users)

app := amigo.New()
app.Include(api)
----

Router options are optional, so `amigo.NewRouter()` is valid. Route options are
optional too. Every registration method returns a relative `Route`. On the
first request, the API recursively builds complete `Operation` values and
registers them in its `http.ServeMux`. Prefixes, tags, and middleware are
inherited from parent routers. The final tags above are
`["api", "users", "read"]`.

`Run` builds the router tree once and gives the final `http.ServeMux` directly
to `http.ListenAndServe`. `Handler` can be used when another server or tool
needs the built `http.Handler`. `API` also implements `http.Handler` for direct
compatibility with `net/http`.
